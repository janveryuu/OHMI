# Importing OHMI mascot assets

1. Extract this ZIP into the root of your existing OHMI project, e.g. `C:\Users\LEGION\Documents\OHMI - Your Circuit Buddy`.
2. The ZIP adds (or may overwrite if you already have matching names):
   - `assets/mascot/ohmi-pixel-front.png`
   - `assets/mascot/ohmi-pixel-turnaround.png`
   - `docs/OHMI_MASCOT.md`
3. Ask Codex to read `AGENTS.md`, `docs/PROJECT_CONTEXT.md`, and `docs/OHMI_MASCOT.md`, validate both PNGs, and acknowledge that the assets are canonical. Do not begin Phase 1 in that task.
4. Prefer a brief reference to `docs/OHMI_MASCOT.md` in the existing `AGENTS.md` rather than replacing the full file. Codex should request approval before any edit if your workflow requires it.

These are transparent raster images, not real 3D geometry or rigged character models.

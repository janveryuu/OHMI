# OHMI Web App + PWA

## Platform

Web. Standalone installable PWA, with adaptive phone, tablet and desktop layouts.

## Product truth

OHMI helps students learn electronics through questions, assignments, screenshot review and beginner guides. This approved stage is a frontend demonstration. No authentication, AI, database, remote uploads or live student records are connected. Demo conversations and selected files remain in session memory. Only appearance and accessibility preferences may persist on this device.

## Stack

User requested Next.js App Router, React, TypeScript, Tailwind, shadcn/ui, Motion and Lucide. This app has an independent package and build under web-app. Existing WXT extension and website remain independent.

## Constraints

Use the exact approved mascot PNG. Preserve teal identity. Do not imply Autodesk affiliation or electrical verification from a screenshot. No production deployment is authorized. Backend integration is a later phase.

## Success

All eight requested surfaces have working local interactions. Responsive navigation, keyboard access, light/dark modes and reduced motion work. Production build and browser flows pass. PWA caches only an explicit public shell.
